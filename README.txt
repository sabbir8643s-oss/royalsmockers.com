ROYALSMOCKERS CUSTOM WEBSITE
=============================

This is the first custom homepage prototype for royalsmockers.com.

Files:
- index.html
- styles.css
- script.js

Open index.html in a browser to preview it.

Before launch:
1. Replace the placeholder WhatsApp/phone/location details.
2. Add your real product images and business information.
3. Confirm the legal-age wording and all applicable South African/local rules.
4. Choose a hosting provider and point royalsmockers.com DNS to the host.
5. Add any required privacy/terms pages.

This prototype intentionally does not include an unrestricted checkout for age-restricted products.
